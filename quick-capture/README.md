# quick-capture

A single text box: type a task, hit Enter, it's in your task list. No JSON editing.

## Status: 🟢 active

Writes directly into [productivity/data.json](../productivity/data.json)'s `tasks` array — a captured item is a normal open task immediately, shown wherever productivity's tile shows open tasks. This node intentionally has no list of its own; it's just the fast-entry point.
