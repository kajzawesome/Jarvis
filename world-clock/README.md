# world-clock

Local time + Brazil time, side by side.

## Status: 🟢 active

No API needed — just `Intl.DateTimeFormat` with a timezone. Edit the `ZONES` array at the top of `collector.js` to add/remove/change zones (must be valid IANA timezone names, e.g. `America/Sao_Paulo`, `America/New_York`, `Europe/Lisbon`).
